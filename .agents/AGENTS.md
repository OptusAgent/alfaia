# Diretrizes Globais do Agente (AGENTS.md)

## Regra de Encerramento de Tarefas (Próximos Passos Obrigatórios)
- **Instrução Permanente**: Sempre que concluir qualquer tarefa, estória, ajuste de código ou etapa de desenvolvimento, o agente DEVE declarar explicitamente qual é a **próxima etapa sugerida no pipeline/workflow**, indicando o próximo papel responsável (`@qa`, `@devops`, `@po`, `@dev` ou Ações do Usuário) e as instruções claras de como prosseguir.
