## Story
**Como** motor de mensageria do ALFAIA,
**quero** uma interface `CanalAdapter` única e um dataclass `Capabilities`,
**para que** trocar UAZAPI por Meta (ou vice-versa) nunca exija mudar regra de negócio (Princípio P6, Decisão A2).

## Acceptance Criteria
1. Interface `CanalAdapter` implementada exatamente com a assinatura de §14.2: `normalizar_webhook`, `enviar_texto`, `enviar_midia`, `enviar_template`, `marcar_lido`, propriedade `capabilities`.
2. `Capabilities` implementado como dataclass frozen com os campos de §14.2: `janela_24h`, `suporta_template`, `requer_delay`, `delay_min_ms`, `delay_max_ms`, `exige_horario_comercial`.
3. Nenhum adapter concreto existe ainda nesta story — apenas o contrato e um adapter fake/in-memory para uso em testes das stories seguintes.
4. Payload de saída de `normalizar_webhook` é sempre o contrato de §6.3 (`tenant_id`, `canal_id`, `provider`, `telefone`, `push_name`, `mensagem`, `midia_url`, `midia_tipo`, `wa_message_id`, `timestamp`, `data_atual`).
5. Normalização de telefone implementada como função compartilhada (não duplicada por adapter): remove não-dígitos; se resultar em 10/11 dígitos sem `55`, prefixa `55`.

## Dev Notes

### Por que esta story vem antes de S-07 (idempotência/webhook) na sequência de dev
Ordem recomendada pelo @sm para o Épico 2: **S-04 → S-07 → S-05 → S-06 → S-08** (arquivo `2.1`→`2.5`), diferente da ordem numérica do PRD (S-04→S-08 sequencial). Justificativa: a interface (S-04) e a infraestrutura de captura/idempotência de webhook (S-07) são compartilhadas pelos dois adapters — construí-las antes evita reescrever a captura de webhook duas vezes (uma por adapter). Isso é julgamento do @sm, não determinação literal do PRD — o usuário pode sobrepor.

### Contrato (fonte literal: PRD §14.2, §6.3)
```python
class CanalAdapter(Protocol):
    def normalizar_webhook(self, raw: bytes, headers: dict) -> list[PayloadNormalizado]: ...
    async def enviar_texto(self, to: str, text: str) -> ResultadoEnvio: ...
    async def enviar_midia(self, to: str, url: str, tipo: str, caption: str | None) -> ResultadoEnvio: ...
    async def enviar_template(self, to: str, nome: str, idioma: str, componentes: list) -> ResultadoEnvio: ...
    async def marcar_lido(self, wa_message_id: str) -> None: ...
    @property
    def capabilities(self) -> Capabilities: ...

@dataclass(frozen=True)
class Capabilities:
    janela_24h: bool
    suporta_template: bool
    requer_delay: bool
    delay_min_ms: int
    delay_max_ms: int
    exige_horario_comercial: bool
```
